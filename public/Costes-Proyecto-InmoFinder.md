# Costes del piloto independiente

El despliegue actual usa frontend estático, una cuenta propia de Supabase y workers Node con Chromium. No depende de créditos de un editor ni de un gateway de IA para clasificar anuncios.

Antes de vender el servicio hay que medir: alojamiento del frontend, base de datos y almacenamiento, horas de navegador por búsqueda, tráfico, retención de capturas, correo y comisiones de facturación. Los importes históricos del prototipo se han retirado porque no están verificados.

Registrar por fuente búsquedas terminadas, capturas útiles, anuncios válidos, errores, tiempo y consumo real. Dividir el coste observado entre clientes activos y búsquedas completadas. No utilizar cifras de capacidad o márgenes sin una prueba de carga y facturas reales.

Durante el piloto, los cobros permanecen desactivados y la revisión de fuentes es supervisada. Véanse `docs/COMMERCIAL_READINESS.md` y `docs/BROWSER_WORKERS.md`.
